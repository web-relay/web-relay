Pair a web app

Open the app in one tab, then enter its full URL. The root URL pairs only the home page; other paths include their subpages. Apps on the same origin can be paired separately.

The browser asks for access to the host. Web Relay routes only to approved app origins and paths. This allows discovery and execution of the app's published actions.
